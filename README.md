# 🧠 MindCare AI

An AI-powered mental health support platform designed for students.  
This project provides mental health screening tests, chatbot assistance, and wellness resources in a simple and user-friendly web interface.

---

## 🌟 Features

- 🤖 AI Mental Health Chatbot
- 😔 Depression Test
- 😰 Anxiety Test
- 😣 Stress Test
- 😨 PTSD Test
- 🚫 Addiction Test
- 😳 Social Anxiety Test
- 🎨 Attractive Responsive UI
- 🔐 Student Login System
- 📊 Score-Based Result Analysis
- 💡 Mental Wellness Resources

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Node.js
- Express.js
- OpenAI API (optional)
